# 💫 About Me

👋 Hi, I’m **Marwan Alkhateeb**, an MSc Cyber Security graduate (Distinction) and BSc Computer Science graduate (2:1) from the **University of the West of England (UWE Bristol)**.  

🧠 I’m passionate about **building secure systems**, **ML-driven threat detection**, and **modern network security** — especially in Zero Trust architectures. My work blends hands-on software engineering with applied cybersecurity research.

🚀 I recently developed **ERDCF** — a real-time **ransomware detection and containment framework** that integrates entropy-based anomaly detection and machine learning into a **FerrumGate ZTNA** pipeline. The project achieved a distinction and was selected by UWE for library inclusion as exemplar research.
