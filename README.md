# About Me

Hi, I'm **Marwan Alkhateeb**, an MSc Cyber Security graduate (Distinction) and BSc Computer Science graduate (2:1) from the **University of the West of England (UWE Bristol)**.

I work on building secure systems, ML-driven threat detection, and modern network security, with a particular focus on Zero Trust architectures. My work combines hands-on software engineering with applied cybersecurity research.

My MSc dissertation, **ERDCF**, is a real-time ransomware detection and containment framework that integrates entropy-based anomaly detection and machine learning into a FerrumGate ZTNA pipeline. It was graded Distinction and selected by UWE for library inclusion as exemplar research.
